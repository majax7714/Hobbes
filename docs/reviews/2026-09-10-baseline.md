## Findings

1. **High: the Java source-free resolve claim exceeds the staging rule.**
   `pipeline/src/hobbes/extract/scipsource.py:1692` copies every file
   below `.mvn/`, `gradle/` and `buildSrc/` without applying the suffix
   filter on the ordinary walk. `_index_java_unit` passes this list to
   the networked resolve stage (`:1924`, `:1935`). A temporary tree with
   `src/Main.java`, `.mvn/Hidden.java`, `gradle/Hidden.kt` and
   `buildSrc/src/Logic.java` retained the latter three in
   `java_build_files`, excluding only the ordinary source. This proves
   source inclusion, not an executed exfiltration. C-66 now names the
   limit; architecture §3.2 is corrected. The product notice still
   overstates it. Fix this boundary and test the exceptional directories
   before considering `build-logic/` or `gradle/plugins` exceptions.

2. **Medium: collapsed recall can credit a different declaration.**
   `bench/oracle/shape/bucket.py:24` strips target qualification;
   `collapsed_recall` (`:137`) groups by source path/line and target
   path/bare name. Two targets `A.run` and `B.run` in the same file,
   reached on one source line, become one pair. A single confirmed
   `A.run` row then reports 1/1 instead of distinguishing the unhit
   `B.run`. The sibling bucket uses the same weak identity, and
   `kind[k]` overwrites kinds when identities collide. H-22 records
   this open bench defect. The effect on cheerio/zod has not been
   quantified; the standing `oracle grade` results are not computed
   by this helper and were not changed.

3. **Medium: the shape join cannot prove that no join miss exists.**
   `bucket_misses` chooses a shape by approximate column distance and
   takes the first lane-A candidate on a line (`bucket.py:116–128`).
   `shapes.mjs:65` visits call expressions only, not constructor
   expressions. The prose's universal attribution of misses to
   below-floor lane-A declarations therefore goes beyond the evidence.
   The diagnostic remains useful for prioritization; exact attribution
   requires a call-site identity and explicit unmatched/ambiguous rows.
   This is recorded with H-22, not as a newly measured cell result.

## Recommendations for the pending decisions

- Keep collapsed recall exploratory until H-22 is fixed. Use canonical
  declaration/overload-family identity and preserve site distinctions;
  audit collisions before promoting the metric to `oracle grade`.
- Function-valued class properties and exported namespace members are
  plausible symbol-floor extensions. Their quoted counts are estimates
  from the diagnostic, not guaranteed recovered edges. Require fixtures
  and compiler grading before accepting either capability.
- Settle constructor identity before adding `new`: the written class
  and the base class supplying an inherited constructor differ.
- Keep a Jelly experiment separate from admitting a third product lane.
  Prefer an explicit, separately labelled flow-target key with its own
  evidence and poison checks over relaxing the existing declaration
  matcher. Following arbitrary values is not established by `tsc`'s
  resolved signature alone; the “one afternoon” estimate is unvalidated.
  Pinning, containment and documented provider limits remain required.
- W0's review-base defect remains open. Review design must distinguish
  outstanding coverage debt from new changes and define fixture ownership;
  this review does not choose between last-green-base and standing debt.
