# Calvin M0-Go — the run (WP-6) · gitleaks · 2026-09-11

**A2 is a fixing, not a product.** Every number on this page is at A2 (commit message + the gold's touched parent symbols, definitions only, no paths — `a2_rev: 3`). The product condition is A0; this page does not measure it.

**Design:** [`../calvin-m0-go.md`](../calvin-m0-go.md) (§2.6 arms, §4 instruments, §5 readings). **Row format:** M0 §5 ([`../calvin-potential.md`](../calvin-potential.md)) plus W, density and declare-holes. Every row carries `"wp": "wp-6"`; the machine rows are `~/.hobbes/bench/calvin-go/wp-6/rows.json`.

**Held constant (M0 §3.3 as amended):**
- **Model and endpoint:** `claude-haiku-4-5-20251001` in every arm, on `https://api.anthropic.com/v1` (OpenAI-compatible), at **model-default sampling**. That is Max's decision for both T runs; O is held to the same, so no temperature is sent.
- **Protocol and template:** adapter protocol **v0.3**, system prompt v2, template **v2** (out-degree cap k = 20), grounder v1 with the gitleaks-notests go-rta key at 8ad8470 (implementers recorded, never bound). The verifier is `hobbes verify` for Go, with generation retried up to 3×.
- **Box:** image `hobbes-session:local` (proxy 0.1.12-beta). `calvin.box.policy` allows `go generate`.
- **Units:** WP-0's 20 keys, 5 per shape, each at its parent. W = 1.0 on every unit.

**Arms (§2.6):**
- **T:** one run is round 1 → rebuild → round 2 → ground → verify. It runs **twice per key** (`t-run1`, `t-run2`), cheapest key first by WP-4's estimate.
- **T-loop:** the same run with one NULL round-trip, one extra exchange inside T's run. It is not a separate run.
- **O:** one `hobbes-session` per key at its parent. It gets the A2 task and `hobbes plan`'s manifest from the task alone. Tools are exec and the file tools; the knowledge tools are withheld. Caps: 30 turns, `--token-budget` 1M prompt tokens, `max_tokens` 4096. M0's stall flags apply: nudge-after 15, stall-after 20, max-nudges 1. O runs **once** on the five keys `ed205a5f63e3` `6411402d434d` `2278a2a97e42` `a971a324fab5` `93acc6e82adb`, the three drop-order keys first. O rows are read only against their paired T rows.

**What "pass" means here.** The verifier runs the parent's guarding tests on the candidate, plus `go build` and `go vet`, plus generation. It does not run the gold's own test changes. So **pass = compiles, generates, and breaks no guarding test**. It is a no-regression floor, not task completion. Because of that, every row also carries a hand reading of the diff against the gold (the O line of the attribution), and RFE is read on the files the diff actually changes (`rfe_changed`, WP-5's correction).

## Recall — O's arm reproduces upstream gitleaks (U/O; not the socket)

`memo.py` counts the gold's added lines an arm reproduces verbatim and in order. It counts only *novel* lines: lines absent from the parent's versions of the touched files, which the arm cannot have copied from context.

- **O `93acc6e82adb`:** 32 of 33 novel lines (0.97), including gold's literal token test values.

## §7 — the next step

The floor did not hold, so §7's fan-out does not start: no A1/A0, no fzf or dagger, no Python keys. The next step is a floor re-test on the same 20 keys at A2, T only, with O's five rows standing (recall-flagged). First, three no-spend changes, each with tests on a `calvin-go/` branch:
1. **A declaration hole.** When a NULL's term is a name the fill introduces, the round-trip offers a NEW_SYMBOL placement (file and region) instead of re-asking the call-site hole. This is declare-before-use, §2.5, and it is M1′ tried as a protocol before any model.
2. **The D-a guard.** The validator refuses a body that carries the render's line-number gutter.
3. **The recall scan as a standing instrument** on every arm, next to HSR.

Then T twice. At this run's actuals that is about $4.7, which is under the round's remaining $20.88.
