## Contradicted (15 rows) — all one shape, all oracle-grain

Every row is a call in `server.go` (:839–:898) or `transport.go`
(:329–:371) on a value of type `*wrappedConn` — declared in
`connection.go:243` as `struct { *Conn; testHooks *connTestHooks }` —
that Hobbes draws to `conn_wrapped_test.wrappedConn.<method>`
(`conn_wrapped_test.go`) and the oracle to `(*Conn).<method>`
(`connection.go`). Both are right for their program: the `_test.go`
file declares `run`, `handlePacket`, `closeWithTransportError`,
`Context`, `HandshakeComplete`, `earlyConnReady`, `destroy` on
`*wrappedConn`, shadowing the promoted `*Conn` methods **in the test
build**, which is the build scip-go indexes (go/packages with tests);
the oracle ran without test packages, where the promoted method is the
callee. **0 hobbes-wrong.** The same fact C-71 registers for
`//go:build` — the semantic graph is one configuration's — holds for
the test build versus the binary build; a full-program RTA (with tests)
would confirm all 15, and needs a bigger box.
