# Oracle lane — the defect record

**What this is.** The oracle grades Hobbes; nothing grades the oracle
except the fixtures and triage. So every defect found in the harness or
an oracle extractor is logged here — what it looked like, what it was,
how it was fixed, and **what it would have cost had it gone unnoticed**
(Max, 2026-08-25: "always honest"). A harness that only records
Hobbes' errors is a harness that flatters itself. Updated in the same
commit as the fix; a defect found but not yet fixed stays here as open.
Reviewed in full on 2026-08-27 — `oracle-defect-review.md` holds the
verdict, the action register (A-1..A-9), the defect-handling method and
the **seen tally** (roots RC-1..RC-7, maintained in the same commit as
any entry that changes it); a new entry here is assigned to a root there.

**Pattern so far.** Six of the first eight are the oracle being *right at a
different grain* than Hobbes (H-3, H-5, H-6, H-7) or *silent in a way
that reads as a result* (H-1, H-4); phase 2 added the harness dropping
Hobbes' own edges and reading the hole as misses (H-12), and twice the
oracle attributing code nobody wrote to a source line (H-13, H-15). Neither shape produces a Hobbes
error — both produce a **false verdict against Hobbes**, and the only
thing that caught them was a fixture with hand-computable truth (H-1,
H-2, H-3 via `testdata/generic`) or triage of the contradicted rows
(H-5, H-6). That is the argument for never quoting a cell's number
before its triage is complete (design §8), restated as evidence.

**Open:** none — H-22 (collapsed-recall identity and shape attribution) was closed the day it was found, its effect measured at 0 / 3 pairs; H-23 (the Java key's member-bare names, the same identity defect on another key) was closed the hour the grader's collapsed line exposed it, the four keys re-merged with positions unchanged. H-11 was closed by A-3 on 2026-08-27. O8's three defects (H-20, H-21) were all found by **triage of the contradicted rows on the first two real cells** — the pattern the tally already names: a new oracle's first foreign repo is where its identity and provenance rules get tested, and both defects were oracle-side, not Hobbes-side. H-9's larger half — dagger's root module as one program (and every subtree that has roots: integration, dagql, cmd — each 24–25 GB) **needs a bigger box**, ~32 GB+ free; flagged 2026-08-25 (Max) and parked until Hobbes gains compute.
