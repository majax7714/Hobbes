# Decision records

One file per decision: `NNN-short-title.md`, numbered sequentially from `001`.
Never renumber or rewrite an accepted record; supersede it with a new one.

Template:

```markdown
# NNN: Title

- Status: proposed | accepted | superseded by NNN
- Date: YYYY-MM-DD

## Context
What forces are at play; link the open-work item in docs/open-work.md.

## Decision
What we will do.

## Consequences
What becomes easier/harder; follow-ups.
```
